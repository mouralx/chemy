# Chemy Scientific Verification & Empirical Benchmark Suite

This document records the scientific verification suite for Chemy's computational algorithms and HTTP REST API microservices. Each verification entry belongs to one of four evidence categories:

- **Analytical Identity Test** — exact symbolic/numerical result derivable from first principles (e.g., stoichiometric balancing, molar mass, pH of strong acid).
- **External Numerical Comparison** — quantitative agreement checked against an independent reference tool (RDKit, NIST, PubChem) or peer-reviewed data.
- **Internal Regression Gate** — output compared against a frozen reference dataset generated by Chemy itself, detecting code regressions but not independently validating accuracy.
- **Qualitative / Heuristic** — output is structurally plausible but has no independent quantitative validation (e.g., environmental pathways, spectroscopic heuristics, lead-exploration scaffolds).

Not all domains have equal evidence depth. Subsystems without external numerical comparison should not be cited as independently validated.
